# PaperCraft 2.30.1 发布检查

本次发布汇总已完成的本地改进，保留内容版本与调用标识。发布前从独立工作副本运行检查，再在新的技能目录副本中验证依赖、官方元信息和代表性README重建命令。完整原始日志在维护者本地归档；这里记录公开可复核的范围。

统一入口的语法、基础、文档保真、嵌图、效果记录、审阅材料、媒体表示、自动发现单元测试及README示例均通过。锁止时序演示从当前源码重新生成，清稿和审阅稿的原生公式XML、表格、斜体、REF字段、书签、超链接、历史黄色及PNG/SVG嵌图核对通过。新建绘图是授权差异：通用保真脚本的drawings差异如实保留，不改写成无条件通过。

锁止时序演示清稿与审阅稿另用LibreOffice重新渲染，各3页，逐页进行模型辅助查看。公开包中的Word PDF为此前经过查看的原生Word导出；本次重建后又检查了另一渲染器，未替换原生Word版本。

执行环境是Windows、Python 3.12.14、已有Python依赖、Arial/Segoe UI及Poppler；Word示例另有LibreOffice渲染。未声称在全新操作系统安装，也未完成所有平台、字体与色觉条件的覆盖。缺依赖须按README配置，不包含运行时或商业字体。

生成代码、技能、参考、模板和DEMO作为一个包提供；`release-content.json`记录文件哈希和汇总内容标识，Git标签定位完整提交。`candidate-content.json`保留历史生成候选标识；其历史“本地未发布”状态不是本次发布状态。发布后的代码身份以 `v2.30.1` 为准。

公开内容核对包含文本、本机路径和Office/PDF内部文本。仅提供通用能力与明确标识的构造演示，未把私人长稿和原始实验图加入本轮提交。本机路径转为相对位置或归档说明，不改数据与首评结论。

固定源码重建、从未见材料生成、模型辅助理解评审和作者认可分别记录。本次发布检查只证明所列执行路径可用；既有比较未证明新版在所有维度胜出，没有真人审稿或审美认可，也不承诺期刊录用。需要质量证据时请同时阅读案例原始材料、前后产物与评审。
