# PaperCraft → FigureCraft 交接单

稿件/父版本与 SHA-256：〔实际文件〕。图号/修改范围：〔重绘、局部修改、只换色或保留〕。

| 项目 | 需要传递的内容 |
|---|---|
| 要回答的问题 | 读者看完图应该能回答的一个具体问题；不写泛化“体现创新” |
| 证据定位 | 原稿段落、公式、源代码/数据文件、版本、哈希及状态；区分示意和测量 |
| 实体/实际对象 | 稳定 ID、类型、数量、所属集合；实际对象与装饰面、图例、重复放大分开 |
| 状态 | 每个实际对象的可核查状态，如占用/空闲、活跃/无效；不凭颜色猜状态 |
| 关系 | 起点 ID → 终点 ID、含义、方向、箭头；明确示意关系与实测因果的区别 |
| 锁定内容 | 数字、地址、单位、标签、拓扑、全部观测、负结果、坐标比较尺度和统计口径 |
| 数据来源 | 真实源文件/列/筛选与排除规则；缺失项；无数据时仅允许有依据的示意图 |
| 正文引用 | 图被哪些段落引用；每处论证依赖图中哪项内容 |
| 图注 | 推荐图注及必要解释；把细小段落说明移入图注，保留图内必要标签 |
| 实际入稿 | 目标宽/高 mm、单/双栏、最小可读字号、整页/列宽约束；从当前版式读取，不把示例宽度当成期刊固定值 |
| 语义配色/深度 | 颜色映射到哪些科学类别；冗余形状/线型；浅立体具体帮助表达哪种关系 |
| 保留和禁止 | 有效图形保留；本轮不能改什么；是否允许重排与裁剪 |

交付：可编辑源、源数据绑定、SVG/PDF/PNG、工具命令与字体、正常/灰度/适用色觉模拟、实际尺寸预览、技术/内容/视觉三类检查结果。

返稿核对：PaperCraft 检查正文—图—图注一致、完整观测与实稿可读性；FigureCraft 检查源规格—几何—导出一致。自动未覆盖关系必须进入人工审阅；缺数据/缺依赖标未完成。最后分别记录技术通过、独立代理审阅、作者认可，不替作者勾选。
