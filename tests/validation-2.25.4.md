# 本地维护与真实长稿试用

本轮使用用户新授权的一份真实材料器件长稿，未向生成者预先给出主贡献答案。原稿、冻结技能、候选技能的入口和全文经匿名独立模型阅读；没有普通提示生成组、真人阅读测试或严格等算力控制。私人原文、图件和记录仅留在用户本地交付中，不进入本包。

修复普通文字与 Word 分页缓存同 run 时被误拒的接续路径；分页缓存保留一次，原生公式、域、链接、历史修订与旧高亮保护不放宽。真实稿复现及新增边界测试、统一技术入口已执行。结果叙事参考只替换一段，明确直接结果、解释观测与控制的分工。

旧版也找到了重要的效率/寿命联合结果；不能把该发现全算作本轮增量。候选入口和因果边界较清楚，但摘要更密、部分科学推断仍需外部复核；最终产物有另存的评后修复。新技能并未创造更强实验或证明研究创新性。

最终文件、测试失败/复验和安装内容标识以本轮本地交付 receipt 为准。版本号只标识文件变化。尚未取得作者最终认可，不承诺期刊接收或任意题材均达到同等视觉水平。
