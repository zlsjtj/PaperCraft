## 第一轮新材料对照：不是全面胜出

原创参考校正材料含粗稿、实现草图、结果表和必要说明，没有预写贡献答案。旧技能、初始新版、新版复跑使用相同输入与继承模型设置，在新上下文完成；预算为近似指导时间，不是严格 token 控制。普通任务提示条件本轮未执行，不能用上轮不同材料替代。

独立模型先读匿名且顺序打乱的前部，再读全文、实际页面和来源。三稿都自主把主线从“新校准/更准算法”转为“继承插值上的接收规则与追溯”，并区分共同子集误差和不同分母误差。旧稿叙事最均衡，新版首跑代价最明确但更密，复跑更轻却淡化摘要内的成本量级。表格成熟度三者近乎相当。因此不记为新版整体胜出。

随后修复真实成稿：标题指向实际被追溯的接收过程；摘要减少同时出现的术语和完整数字；方法保留完整插值式和坏参考不能直接删除的原因；表格保持原序与全部数值，整理分组/对齐；行内变量改用一致数学排版。该稿是已看评语后的开发修复，不再称独立验证。

## 最终冻结后的另一新材料

使用另一原创栅格编辑材料包，只提供粗稿、设计、代码草图、完整表和 DEMO 边界，不提供主旨。最终版在新上下文自主选择“按事务撤销边界保留瓦片端点”，解释 A→B→C 为什么要保留最早与最终状态；没有将字典、缓存或已有画笔拆成独立创新。

首稿保留全部三组数据、无重复写入时不省载荷、所有给定 CPU 均更高，以及事务边界恢复和逐操作历史不同的限制。独立模型核对来源及两页实际清稿，确认主线与数值，指出 abort/分支的错误后果解释不足、表后间距偏小及来源标识可更直接。随后的限定产物修复单独保存，不改冻结技能，也不把修复后的稿件冒充第一次生成。

这是最终版在未见材料上的一次成功任务完成，不是旧版/普通提示对照，也不是“稳定全面优于旧版”的因果证据。实际访问清单确认新呈现参考被读取；结果配对示例没有被该生成者单独打开，不能虚称该文件导致了新稿改善。
