# 同一教学材料的三次改写

原材料和固定边界见 [input.md](input.md)：三个构造记录，候选节点计算次数 12/48/120，基线每次 120，输出相同；没有时间、峰值内存、并发记录或一般正确性证明。

产物分别为[普通提示](ordinary.md)、[修改前技能](before.md)、[修改后技能](after.md)。每份包含引言与结果段，来自独立执行上下文，不是维护者手写三个“好坏示范”。

独立代理先匿名阅读。三份均把选择性失效、调度和有效结果复用作为同一机制，保留签名/依赖版本检查及全局修改无计数优势。旧版明确说明失效从变化节点开始；新版更直接逐例对照 120 个基线节点；普通提示也能得到连贯结果。没有证据认定新版稳定更好读，故不淘汰旧文本、不靠词数判胜负。

复用时先给执行者 input.md 及相同篇幅/交付要求，另外冻结模型和预算，再决定是否加载技能。已经阅读本案例的执行者不再是未见材料条件。没有真实读者参与，也没有阅读时间或人工审美认可。
