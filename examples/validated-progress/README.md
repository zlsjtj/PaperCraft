# 验证过的进度记录：从字段清单到证据叙事

原创教学 DEMO，四条故障轨迹和操作计数是构造材料，不是实机测试。本例在冻结候选指令后的新上下文生成。执行者收到原稿、实现说明、结果表和技能，没有收到预写主旨或维护者的事实评审清单。

`export-draft.md`、`implementation.txt`、`results.csv` 是输入；`first-draft.md` 为首个完整稿；`final.md` 是一次自主复读后的稿件。`entry-candidates.md` 保存两条真实写出的入口，`changes.md` 说明得到和失去什么。`self_edit.py` 记录该次文字变动，不能把固定文字脚本当成从新材料自主提炼的生成器。

稿件从“旧扫描已正确，但要重新检查整个输出”提出问题，用写入返回与持久化的区别解释记录顺序，再连接较少检查、额外同步、重放与回退。它没有把常见校验技术说成历史首创，也没有把操作计数称为测速。方法字段仍在正文，摘要不再在结果前逐条展开同步次序。

这不是普通提示/旧技能/新技能三条件实验，也没有重复采样。本次新上下文生成加一次自修，只支持一个有限迁移样本。独立模型的审阅另列于本轮验收；不声称真实读者或作者认可。该材料公开作示例后，今后不能继续算未见材料。

`reviewed.md` 是独立评语后的局部修复：明确 header 计数不包含全部验证 I/O，并压缩一次重复；`final.md` 仍保留首次自修结果，不倒写评审结论。
