# 连续表面与矢量标注

适用缺口是准确几何仍有分片细纹、曲面缺乏连续性。该路径输出可重建的透明表面位图，保留独立矢量标注。不是全矢量、照片级渲染或物理仿真，也不自动比原矢量图好。

`mesh_surface.py` 的 `render(faces, right, up, view)` 接受相互正交的屏幕向右、向上及朝向观察者的单位向量。每个面提供凸多边形 `p`（Nx3）、向外法向 `n`、`role` 和 `color`；可选 `base_color` 为不预乘光照的颜色、`vertex_normals`（Nx3）为连续曲面的逐顶点法向。平面不提供顶点法向。不得跨材料界面平滑法向。返回 RGBA 图层、可见材料掩码、投影包围盒和有限导出记录；以同一投影包围盒定位标签，不能缩放表面后沿用旧标签坐标。

背向面剔除后，逐三角形以重心插值计算深度；同一采样点保留最靠近观察者的面，再计算连续法向的示意明暗。没有透明材质、光线折射、互投影或物理模拟，不能把绘图明暗作为测量场。支持的多边形必须是凸面；非凸面先在来源几何中可靠分割。相机和单位需由调用者提供，不推断材料结构。

`light=(x,y,z)` 和 `ambient=0.4` 是可选的展示参数，不必为每个新相机修改组件源码。光向为世界坐标，朝向由实际可见曲面决定。`px_per_unit` 是几何单位的采样密度，不是最终dpi；应按表面图层最终放置毫米数计算实际dpi，不能把低分辨率表面放大到600 dpi画布就称为600 dpi图形。新杯柱试用确实遇到了这两个问题，首稿与自修保留在本地交付中。

若可见面与事实、轮廓或计数冲突，应修正源几何。若渲染层并没有改善解释或质感，就保留旧图，不为了使用新组件而替换它。只改善表面细纹时不称为整个机制图重设计。

## 实际选择

弯曲双层案例沿用[原始矢量版](../space-illustrations/strip/selected/figure.png)的几何、视角、标签、160 × 85 mm画布和端面局部。`selected/figure.png` 是本轮选中图：连续表面消除了矢量分片的可见细纹；没有声称把端面局部或整体构图升级到顶刊水准。主图是透明位图表面加矢量物理边界，端面、标签与引线仍是矢量。

曾尝试把端面扩大为一小段实体，独立模型认为体积更清楚，但容易读成截下的新样品。因此最终保留原端面，只采用连续主曲面。另一组包覆颗粒的解析球面试画也未被采用：更暗的切面增加空腔联想，扩大开口又使内核像独立球。新渲染器并非默认优胜；这两次判断都不是人工审美认可。

## 从源码重建

需要 Python 3、NumPy、Pillow、ReportLab、pypdf，以及外部 Poppler `pdftoppm` 和可读的普通/粗体 TrueType 字体。四个源码文件均在本目录；没有用户绝对路径依赖。输出目录必须不存在。

```powershell
python -B build_continuous.py --out ./rebuild --font /path/to/Arial.ttf --bold-font /path/to/Arial-Bold.ttf --pdftoppm /path/to/pdftoppm
python -B test_surface.py
```

`figure.svg` / `figure.pdf` 内含表面位图，`strip-surface.png` 是单独表面层；源几何在 `geometry_scene.py`。`strip-materials.png` 是类别掩码，编号见 JSON，不是连续测量值。不能将混合SVG称为全矢量；需要全矢量时采用原案例。

`geometry-and-checks.json` 区分本后端400个固定可见像素的深度复核，与旧矢量BSP后端的历史对照检查。采样检查不代表每像素或任意几何都已证明正确。新后端仅负责不透明凸面，示意光照没有物理仿真含义。此方法不要求所有机制图使用空间几何，定量图继续采用准确二维编码。
