# Raw material package

Status: ORIGINAL FICTIONAL DEMO, prepared 2026-09-30 for a writing-skill exercise.

Every numerical result is an authored fixture. No implementation, trace replay,
simulation, physical experiment, production deployment, or statistical trial was
performed. The descriptions specify a hypothetical system; they are not a record
of completed engineering work. Published research facts appear only with source
identifiers S1–S3. Their empirical results are not reused as DEMO results.

Files:
- `raw_draft.md`: unpolished English manuscript text.
- `implementation_notes.md`: algorithm and accounting specification.
- `workload_notes.md`: scenario and data-field definitions.
- `fixed_results.csv`: fixed, explicitly fictional results.
- `sources.md`: three primary research sources and a limited retrieval record.

All policies, including the simple capped policy, use the same 64 MiB payload
capacity. Policy names in this package are local DEMO identifiers, not names of
published methods. No claim of literature priority is supplied. There is no
per-request trace behind the CSV, so aggregate arithmetic can be checked but
trace realizability and performance cannot be independently reproduced.
