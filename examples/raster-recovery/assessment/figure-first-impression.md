# 匿名图形第一印象

评审性质：独立上下文模型评审；没有真实人类参与。只读取匿名作品目录；未读取版本映射、技能或作者理由，未推断版本。观察顺序为 V → J → R，每个候选依次看 figure1-160mm96dpi.png 与 figure2-160mm96dpi.png。本文件在阅读完整分辨率图、caption、全文、页面和 facts **之前**记录。160 mm/96 dpi 是约 605 px 的模拟入稿视图；这是模型视图，不能当作真实显示器物理尺寸的人类实验。

## V

### Figure 1

- 第一眼：左边是二维采样网格，前五行已完成，第 5 行从右向左走；右上放大这一行，把它拆为 b0–b3。青色样本已封存，黄色样本仍在易失状态，红色位置被中断。紫色框给出重启 q = 88、r5/k8/c7、(28,30) mm；入场在右端 c15。
- 可以直接读出的关系：逻辑恢复到第一个缺失样本，运动需要从右侧入场点重新定位。图中用紫色指引把目标 c7 接到重启说明。
- 第一疑点：为什么图上红色中断点在 c5，而恢复目标在 c7，需要读 k/c 对应和下方文字才能消解；黄色两点为什么重复，主要靠紫框的 “Repeat k8 and k9” 说明。
- 入稿感受：布局完整、色彩克制、分块有层次。列号、k 范围、图例和副标题相当小；读者需在网格、放大图、紫框、底部图例之间往返。右下解释性语句占了一块区域，信息明确但有“图内说明书”的感觉。

### Figure 2

- 第一眼：q 与物理位置共同进入采集，样本进易失缓冲，再写持久块和行检查点。复位先 Home，恢复读取器检查持久信息，得到 first missing q，再 row anchor。
- 可以直接读出的关系：截断会丢缓冲；读取器接受连续前缀；定位与逻辑序号分别恢复后回到采集。1024 B 数据、24 B seal、A/B 64 B 槽和主要时间可见。
- 第一疑点：数条长回线和右侧嵌套支路需要追踪，左侧虚线恢复 q、实线建立位置的对应不够一眼明白；b0–b3 在写入框内看起来同等有效，停止于缺口的规则主要依赖正文小字。
- 入稿感受：精致但说明文字偏多，尤其读取器、持久化和检查点框中的小字。主流程与重启流程有概念层次，但没有完全形成清爽的直读路线。

## J

### Figure 1

- 第一眼：上半部是采样网格与状态图例，右边显著给出 q = 88 和坐标，下半部把整行拉宽；b0/b1 青色、b2 中黄色和红色、b3 空白。
- 可以直接读出的关系：封存的是块 0/1，k8/9 易失、k10 中断；重启圈在 c7，入口圈在 c15；向左行进。
- 第一疑点：需要从右上图例把 k8/9/10 对应到底部 c7/6/5；为什么 k = 8 对应 c = 7 没有显式映射动作，但两个坐标同时列出。上部轴注释 r、0、x(mm)、60 很靠近，读第一眼略拥挤。
- 入稿感受：底部行图大而清楚，文字普遍比 V 大，阅读速度较快。空白与大文字框有些不均衡，顶部图例像一段说明清单。技术示意成熟但样式较朴素，立体感不明显。

### Figure 2

- 第一眼：上方前向链为序号/坐标 → 采集 → 四记录缓冲 → payload/seal；下方重启链为 Home → Read slots + seals → First q → Row anchor → Acquire。
- 可以直接读出的关系：先数据后封印；先确定缺失逻辑序号，再恢复物理位置。两条水平流程本身好读。
- 第一疑点：上方持久块、A/B 槽与下方读取器的右外侧连线较绕；“4 blocks: checkpoint / 1 ms” 放在缓冲区下面，第一眼可能误以为属于缓冲行为。first q、row anchor 与上方 ordinal/coordinate 没有图形闭合，读者需自己补全。
- 入稿感受：字号和块宽比 V 宽松，缓冲区四格能直接表示数量。验证内容仍是一段分离文字，停止规则没有在实例状态上画出来；图形更像流程摘要。

## R

### Figure 1

- 第一眼：重点是“下一个样本在哪里”；网格第 5 行被框出，右边从检查点、封存、易失、中断顺序导向重启 q = 88，再给出入口 c15。底部保持同样横向坐标展开这一行。
- 可以直接读出的关系：b0+b1 共 8 个封存记录；k8/9 复位后重采；k10 没完成；r5/k8 → c7 是明确的映射动作。右到左的遍历箭头与入口关系相符。
- 第一疑点：未来行的浅灰圆点与已完成行的深灰圆点需要仔细区分，右边没有 pending 图例；底部只突出恢复点 c7，入口 c15 的圈只在主网格里出现。
- 入稿感受：信息分组、线条和留白比较自然，标题、重启框和高亮行形成明确主次。相对清爽，右侧仍需要读解释文字，但不是大段注脚。没有明显立体效果，却有稳定、统一的论文图气质。

### Figure 2

- 第一眼：上下两段明确区分前向采集与重启。上方四样本 → payload → seal → A/B checkpoint；下方 Home → reader → row anchor → acquire。reader 直接展示 b0/b1 有效、b2 无效、b3 不再接纳。
- 可以直接读出的关系：逻辑 q = 88 沿虚线直接去 Acquire，物理 (x,y) 从 Row anchor 去 Acquire，两种结果分开汇合。读取器里的 ✓/×/— 比纯文字更能解释连续前缀和遇缺口停止。
- 第一疑点：前向 Acquire 没有独立方框，10 ms/acquisition 写在缓冲下面，第一次扫读可能把采集看成缓冲本身。下方 b2 错误和 b3 未接受的含义仍要靠 “stop at first invalid/absent” 确认。
- 入稿感受：总体最容易按视觉次序读完，物理和逻辑结果的分流是实质解释性设计。文字比 V 少但必要状态没有消失；彩色方框与连接线成熟一致，个别右上/下方说明略小。
