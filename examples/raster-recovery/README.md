## 从源码重建

在 PaperCraft 仓库根目录运行，提供实际字体和 Poppler 路径，输出目录必须尚不存在：

```powershell
python -m pip install -r examples/raster-recovery/requirements.txt
python examples/raster-recovery/source/build.py --material examples/raster-recovery/material --out rebuild-raster --font "$env:WINDIR/Fonts/arial.ttf" --bold-font "$env:WINDIR/Fonts/arialbd.ttf" --poppler (Get-Command pdftoppm).Source --final
```

默认定位本仓库的文档脚本；安装结构不同可加 `--paper-skill`。本例绘图使用原生SVG和ReportLab矢量PDF，不调用FigureCraft场景渲染器或关系组件。图件固定源码可重建，不代表脚本能够从自然语言自主发现贡献。自然语言生成与评审是上面的独立执行记录。

清稿与黄色审阅稿是独立Word，黄色相对原始DEMO原稿，**不是原生修订**。PDF重新生成需宿主 documents 渲染工具、LibreOffice与Poppler；示例不捆绑二进制运行时和字体。新目录重建只改输出，原稿不变。源码保留 `--final` 前的首轮文字供追溯，但评后来源应以说明为准，不能用它复刻或改写匿名首轮记录。
