# 图文呈现与透明审阅

“面子工程”包括科学插图的造型、构图与整页的完成度。格式与准确性是底线；外观提升必须在实际作品中成立。不要把某一本期刊当成单一风格。空间对象造型单薄、剖面像贴片时，先读[对象造型工作页](object-illustration.md)；操作状态与部件对应不清时，读[过滤组件案例](../examples/visual-editorial/README.md)。按实际缺口选案例，不固定从框图或过滤器外形起步。

## 先完成一个真正的图文设计，再推广

1. **确定最有价值的读图变化。** 从原稿找出论文在哪一步需要画面帮助：对象内部是什么、哪些部件一起改变、谁与谁对应，或哪组结果值得比较。写下一句读图结论，同时锁定不能失去的关系。文字段落先解释问题和意义，图承担结构或变化，图注补读图规则；不要让三者复述同一份清单。
2. **从参考作品学习具体画法。** 打开原图，而不是只读颜色表。找出一个可迁移的处理，例如连续边界表示内外、共同基准对齐不同状态、剖开局部显露内部、形状和遮挡区分构件。说明它为何适合本研究对象。没有可用参考时从对象结构设计，不编造“仿照顶刊”。不复制受限图片，不引入原材料未提供的空间、机制或性能关系。
3. **选择表示与工具。** 对一个尚不明确的关键图比较至多两种实质不同的组织：例如对齐状态便于逐项对应，整体加局部展开便于理解包含关系。若反馈针对整幅质感和阅读层次，先画出包含主体、上下文和标签区的同尺寸完整草图，比较主体所占空间、轮廓与阅读方向；不要先把旧构图中的每个局部精修完。只有关键空间关系尚未解明时，先试画开口、贴合或可见面，再放回完整草图。现有组件只能画近似图标时，改用可编辑曲线、裁切或参数化几何；不要把库里有什么形状当成研究对象的外形。信息组织已清楚且整幅比例有效时可保留布局，单独重画对象。定量关系保持真实二维编码。
4. **在成图上完成设计。** 让主对象、辅助结构、标注有清楚的视觉主次。外轮廓决定辨识，遮挡和连续边界决定体积，接触处决定对象是否悬浮；之后才用少量明暗区分表面方向。弯曲表面可连续过渡，切面保持平整；同一个轮廓内随意加亮斑不构成结构。对照参考中一个具体处理，指出新图哪一处已实现、哪一处仍不足。标签紧邻所属对象或有唯一引线，减少文字后复查归属与状态，不让图注替错误画面辩护。辅助底座、背景和剖切面若比核心关系更抢眼，改变其展示范围、视角或视觉重量，而非只给主对象加高光；未测比例可为解释选取，但不能修改测量几何或隐藏必要结构。没有对应工具或造型能力时保留准确候选并明确差距。
5. **带正文与图注一起入稿。** 同宽比较旧图、首个候选和选中图，查看实际 Word/PDF 页面。判断主旨是否先被看到，层次与留白是否协调，对象是否具体可信，是否仍像罗列组件的讲义。保留好的旧句和旧图；候选产生歧义就修或回退。首轮、自修及外部意见后的修复分别保存。没有真实读者时只记模型辅助判断，不写审美获认可。

这一流程由 PaperCraft 完成选图和成稿闭环。FigureCraft 可承担绘制与语义检查，但调用成功、无重叠和颜色一致都不是结束条件。没有授权改整篇时，不越过局部范围。

## 让整套图接着论证往前走

全文任务先把拟用图放在对应正文旁，用一句普通领域语言写出每图让读者多理解了什么，以及下一处证据要回答什么。若相邻两图都在介绍部件，结果却只剩数据清单，先重新分工；不为凑齐“总览、方法、结果”各添一张图。已有图可以合并、保留或撤下，但论文需要的事实必须有可读落点。

对最关键的跨图连接实际做一版：正文提出具体困难，机制图显出解决困难的关系，结果比较检验这项选择的收益与代价。三者使用同一对象名称和比较口径，但不重复同一解释段。形状可以因任务不同而改变：结构图用适合对象的轮廓，结果图用真实二维尺度；共同语义与字号比共同模板更重要。方案取舍以整页理解为准，单图更漂亮却使主张和证据脱节时，调整或退回。

结果图的视觉重点也要体现结论的成立条件。例如某方法更快但未通过精度条件，不能只用醒目的最高柱暗示最优；让速度和资格在同一阅读路径可见，并保留失败比较。数值很多时，从完整表或来源数据生成有判别力的比较图，正文保留必要完整记录；不把删掉不利行当作图文减负，也不把每个字段都塞进图。

将选定整套图嵌入后，连续读标题、摘要、各图和附近段落。记录一个被建立的连接及一个残留代价；“字体统一、颜色一致”只记录为排版动作。完整开发案例见[热传输图文组](../examples/heat-story/README.md)：包含基线、首次成图、选择及修复、数据来源与实际页面，不代表通用布局或真实实验。

读取当次投稿目标的真实规范；“希望像顶刊插图一样成熟”不等于改投或套用它的字号。缺少数据只影响依赖数据的图，不阻止已有事实足够的机制图。定量图保留来源、分母、尺度、样本、误差与失败；不以 AI 位图替代精确性能编码。

## 把主比较变成页面上的阅读路径

先指出读者要在哪些行列间作比较，再决定层次与对齐。以下延续[取消预约槽位的虚构案例](result-pair-example.md)，不是所有论文的表格模板。

**修改前的实际段落与表题：** “Table 1 gives all outputs. L1 obtains 136,800 timely completions in the burst. L2 obtains 194,750 under skew. CPU values are also listed.” / “Table 1 Results.” 页面把案例名、模式和数值全部左对齐，所有格线同样重，正文把两个不同基线的最高值并列。

**修改后的段落与表题：** “Table 1 pairs each change with its own baseline. Read the burst and steady rows together to test whether early release helps beyond cancellation; read the skew rows separately to assess the inherited borrowing rule.” / “Table 1 Constructed completions and CPU cost for each matched comparison.” 表中保留原始行序和单元格内容：

| Case | Mode | Timely completions | CPU core seconds |
|---|---|---:|---:|
| burst | L0 | 120,000 | 360 |
| burst | L1 | 136,800 | 372 |
| steady | L0 | 117,600 | 104 |
| steady | L1 | 117,120 | 112 |
| skew | L1 | 180,500 | 420 |
| skew | L2 | 194,750 | 443 |

在最终 Word 中，案例与模式仍是独立单元格，不合并或删除重复名称；各案例起始行加略强的横线，组内用较轻的线，数值右对齐。表头允许自然换行并留出内边距；不缩小整表去迁就等宽列，也不单独加粗最大的完成数。这样行分组表明比较基线，列对齐使完成数和 CPU 代价能一起扫读。Markdown 只能预览内容与对齐，最终行线、字号及分页要在渲染页上判断。

页面动作也应有明确对象。例如原页的长标题占三行、首节标题孤立在页底、表题与表分开时，先收紧标题到真实主贡献，调整标题字号和段后距离；节标题与下一段、表题与首行同页；清除正文继承的整页 keep-with-next 链。随后检查摘要到方法的间距、公式前后行距及表后的解释是否连续，不用把所有段落缩成小字来制造“成熟”。行内变量按数学记号排版，与原生公式一致；操作现有普通文本 run，不重建原生数学对象。

这类修改的记录应能回答“哪组更容易比较、为什么”，而不只写“统一字体”。若约定不改表值与结构，就逐 cell 核对文字、顺序、公式和合并信息，并单独记录 tblPr、tcPr、段落及 run 的属性变化。此时表 XML 预期不同，不能写成“整个表 XML 相同”。

## Word 保护

对原包定位修改，保留 OMML、表格、图片、脚注/尾注、域、引用、书签和交叉引用。记录前后数量与语义变化；存在旧修订时保留状态，不自动接受旧修订。复杂对象用经过验证的格式感知路径；辅助工具拒绝某类段落时，不绕过拒绝后仍称对象已保留。

## 审阅文件

新增/重写文字黄色高亮；纯移动和删除记录原位置、改后位置或删除位置、前后文、目的、依据及确认项。格式变化记录具体属性；图表公式变化记录前后对象和检查。审阅稿不是原生 Track Changes，除非实际写入并验证了 Word 修订对象。

现有作者高亮不能被清稿功能全部清除。通常从同一补丁分别生成清稿与审阅稿，只去掉本轮编辑黄标；如有对应同一版本的独立清稿，先验证除已知编辑高亮外的内容和对象完全一致，才可恢复其高亮状态。无法确认来源的高亮保留。父版已有黄色时，另给本轮段落/对象变化索引，不能说“全部黄色都是本轮修改”。报告放中文说明、标题候选、证据/变更表，正文保持学术语言。

## 实际验收

记录输入/输出哈希；检查 ZIP、正文、公式图表、域、文献和交叉引用目标、新增改文与映射。计数不能证明图内容正确，保存不能证明分页合格。

用真实 documents 渲染器逐页看两个最终 Word（交付清洁稿时也需看）。检查截断、重叠、孤立标题、图注分页和字号。失败时说明故障与未验收范围，不以 XML 通过顶替。视觉检查与作者科学认可分开记录。

[变化映射模板](../templates/change-map.md) 可与诊断报告一起生成。报告不能替代正文的关键方法。
