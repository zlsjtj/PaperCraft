# 主编辑路径

适用于全文精修和重大贡献改写。先阅读全文与表图，从实际比较决定论证类型：方法改变要解释操作为何必要，材料替换要分开器件结果与性质证据，经验发现要说明哪组对照改变了认识。需要参考完整写法时，再按这个问题选择[方法与工程案例](result-pair-example.md)或[材料与器件接续](material-evidence-continuation.md)，不默认用计算案例的术语、步骤或篇幅组织所有论文。引言改写要读完其连续中段，不能只读题目、摘要和贡献末段。图文组织接续[呈现动作](presentation-review.md)，机制入口与主图接续[研究故事与主图](story-and-main-figure.md)。局部任务只进入受影响部分。

## 从实际差别选出中心判断

先查来源中已有办法能完成什么、本研究改变了哪项操作、这项改变让什么结果成为可能或付出什么代价。用一个能想象的操作讲清差别，再给它贡献名称。原题目、组件清单和“最高提升”都不能替你完成这个选择。简单办法若已提供同样能力，就找仍有证据的成本、可靠性、范围或机制差别；没有剩余差别时不强造创新。

然后选择论文要让读者作出的一个主要判断：这项改变是否值得采用、一个机制解释是否成立、原有认识在哪个条件下需要修正，或一个方案为何不值得继续。选择由现有对照和边界决定，不能先定宏大贡献再拼支持句。用最有判别力的正反结果回答它；未必是最大数字，也未必是性能。先分清每组结果回答什么：有效性、实现必要性、因果归属还是适用条件；同一组对照不能默认承担全部作用。选择哪一组先写，要看读者作出这个判断先缺什么，而非把所有组依次报齐。没有直接对照时，能解释设计如何工作的操作链，不能冒充它优于已有工作的证明。

把工程必要性与收益归因分开写。源材料中的失效后果可以解释为何需要某个决定：省掉它，一次操作会在哪里不能成立？这不等于该部件的独立收益已被测出。先把必要决定接到操作，再在比较处说明整套结果能归到什么范围；不要因没有消融而把方法压成名称，也不要以必要性补足缺失消融。不虚构故障经历、实验、阈值或引用。

## 两条路线要写到能比较，而不只换开头

全文或重大贡献改写时，先保留原稿，再用同一证据各写一段可连续阅读的短稿，覆盖入口、关键方法和主结果。两版应让读者通过不同的推理得到判断：例如一版先理解改变为何必要，再看它何时有用；另一版先看到决定取舍的结果，再追问何种设计使它成立。按材料选择路线，不强套“机制版/性能版”。只写两个标题、摘要首句或同一术语列表的不同次序，不足以比较。

选稿时直接读到结果：读者先知道什么、还要自行补哪一步、哪项次要事实抢走了注意？以实际句子和段落连接取舍，保留旧稿更具体的关系。两版若没有实质差别，回到中心判断重选一次；不要继续增加同义版本。既有主线清楚的续改可保留它，只试受影响的连接，不强制重写全篇。

引言中段过重时，先列出同一段正在完成的不同任务，而不是先规定它应有几段。材料的使用理由、传输约束、反应风险与本文选择可能各需一个论证单元；几篇文献也可能应按所回答的问题合在一起。比较“问题与相关工作配对”和“先说明研究选择、再建立要求”等真正不同的出现顺序，保留重要文献的对象、改变、结果和原用途。将能级工作归在稳定性标题下、把不同宿主研究统称为同一应用，都会制造新的误读。移动后重新检查代词和共同限定覆盖了哪些工作；引用数量不变并不证明归属未变。分段、合并和先后次序要实际进入选稿，不能用“进一步”“另一要求”等导航句替代。

## 让选定路线进入整稿

**入口把改变接到判断。** 标题保留研究身份。摘要先完成一条可复述的论证，再放必要条件、决定性结果和相应代价；材料全名、配置和测试清单放到承担解释的正文位置。引言交代已有能力及剩余问题，末段接本文实际选择与检验，不再次报齐摘要数字。强化文献比较前查原始来源；未测方法不能写成被本文击败，首创未定仍可完成有限定位。

**方法使抽象贡献成为动作。** 沿一个有来源的操作写出对象、变化、所需决定及后果，必要的初始化、失败出口和适用条件留在旁边。常规步骤压缩为实现交代；承担中心改变的工程要解释到读者能知道它何时起作用。若“协同、解耦、保障”等词遮住原来清楚的动作，就恢复具体句子，参见[保留旧优势的装配案例](../examples/replacement-story/README.md)。

**结果按判断组织，表格保留检索。** 将同一选择的收益、代价、资格和反例放在连续阅读范围，保留比较对象、分母与条件。先解释哪组对照改变结论，再由完整表承载逐项数值；不要先排峰值，再把反例作为结尾免责声明。一个简单对照只能排除一种解释时，让它承担这个作用，不升成完整证明。

辅助表征的次序由它能回答的问题决定。器件或系统收益已经成立、来源尚未拆分时，可以先给收益及直接改变其解释的测试条件，再分别测材料/部件性质；不要因两个独立性质都较好，就让全文顺序暗示它们已经解释了整机寿命或性能。写出相邻两组证据的实际接点：上一组留下哪个问题，下一组测到哪项量，还剩什么。改变偏置与经历操作应力是不同问题，表面与埋藏界面也是不同对象，不能让“进一步表征”把这些区别抹平。可直接比较的连续写法见[材料与器件证据的接续](material-evidence-continuation.md)。成熟稿已有准确摘要和主结果时可以保留它们，但引言仍可能需要重分论证单元和重组文献；是否重排实验段由实际阅读问题决定，不为改动量而改。

因果解释仍须说明比较同时改变了什么、为何不能分开。只把“due to”改成“consistent with”没有解决归因；相同结论的多次观测也不是独立因果证据。某一解释未成立，不自动否定另一项独立结果。结论回到证据支持的选择及决定性未解问题，不再列齐步骤和峰值。正文解释研究，中文记录解释编辑决定。

## 自修后才映射到文件

保存选定首稿，连续读标题、摘要、完整引言、关键方法、主结果和结论。自修针对仍需读者补出的那一步：将相同研究要求的工作成组、移动一组配对结果、恢复被抽象名称替代的动作，或让辅助事实退到解释处。实际改动后重读前后连接，记录一个具体改善及代价；语法替换、字数下降和无错都不是结构改进的证据。

再回来源反查主要比较同时变化的因素、关键操作的成立与失败条件，核对数字、引用、负结果和因果动词。完整数据和必要条件保持在论文中，不靠移去编辑报告减负。科学边界放在它约束的主张旁，重复的泛泛免责声明可合并。

将选定文字及顺序落入实际文件，保留格式、公式等受保护对象。文件 API 是装配路径，不是编辑范围：同一段不能整段替换时，按 inspect 的普通片段或 authored prose 接续能力处理已选文字；不要倒过来只写工具碰巧能匹配的短句。图、图注和相邻结果需要重排时，用[整块移动工具](../scripts/move_body_block.py)及[inspect/move 用法](complex-word.md)保留原 XML；不能重建对象绕过书签、域、节和历史修订保护。保留段号映射并统一引用，无法实现的移动如实交接，不能复制关键结果冒充已重排。在确切 Word 页面读完这条路线，再接[呈现动作](presentation-review.md)与[读者评后修稿](reader-effect.md)。

## 完成与证据范围

保留首次稿、自修稿和评后稿；编辑者负责把已确认的问题修回同一作品。独立模型复述不冒称真人理解、作者接受或真实审稿。开发时看过评语的材料只证明定向修订，迁移检验另用未预设主旨的材料。缺口未推翻有限主张时交付现有证据支持的成稿；没有明确新假设时保留较好版本和具体限制，不重复抽样挑最好结果。
