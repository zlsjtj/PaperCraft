# 将对象画到足以承担解释

适用于空间包含、层状结构、曲面、开口或剖面的视觉精修。它不要求所有论文使用立体图，逻辑关系和定量图仍按自己的任务选表示。

先把参照作品与当前图放到相近阅读宽度，找出最影响质感与理解的一处区别：参照靠什么轮廓辨认对象，哪条连续边界让内外可读，哪里有遮挡，哪个局部被展开。用这些具体关系选工具。色板只是其中一层；不能把参考医学对象换成研究名词，也不擅自复制原图。

## 把空间关系放进完整构图

空间关系不确定时，在一个主对象上作实际试画。完整外壳不能透出内部；开口需要可见的边缘厚度，露出的曲面应接到正确边界；剖切内核与只移除包覆层是不同操作。沿弯曲对象的层必须连续贴合，不能用平行移位制造脱层。画面视角与光向可以为解释选择，未知尺寸不能包装成测量结果。已有几何正确而整幅仍不成熟时，从主体与上下文的比例、视角和标签区域重新比较，不默认继续修材质。

可以沿用现有代码，但若椭圆或多边形的拼接在轮廓处不成立，改造几何本身。二维矢量曲线与裁切可以完成许多插图；确定的空间结构可先建立参数化几何再投影，保留相机、切面和源参数。曲面与端面相交时，按同一视向决定哪些面可见及遮挡顺序；全画后靠移位置消除穿插会制造新的空间错误。

若准确的矢量分片在曲面上产生假纹理，先消除内部描边或合并可连续填充的面；仍有接缝时，可比较“连续曲面渲染层＋独立矢量标注”。FigureCraft 可用时由其 `references/surface-rendering.md` 与 `scripts/surface_renderer.py` 接续；PaperCraft的[连续表面案例](../examples/surface-rendering/README.md)保留独立可重建的历史快照，不是另一份需要同时修改的主实现。采用混合表示须交付几何、渲染源码及位图层，并明确它不是全矢量；用户要求全矢量时保留原路线，不能静默降低可编辑性。更物理的明暗也可能加重空腔误解，所以不默认选新后端。复杂有机造型仍需要合适工具与来源，不由这个小渲染器冒充。

局部正确后安排主对象和必要上下文。示意剖开不是实际裂缝；细节重复不是新样品；运动箭头不是数据流。只为确认身份而需要的说明可以短而明确地保留。避免为了少字而让读者猜对象。

## 让精修有具体目标

不要平均加强所有边线：主轮廓、内部交界与引线分别处理。相同表面共享光照，曲面以连续明暗辅助辨识，切面与曲面有所区别；接触处只需局部遮挡或克制的接触阴影，不必把所有对象变成发亮塑料。局部图若丢失与主体的联系，保留足以辨认对象的邻近结构，明确哪些边是取景裁切、哪些是实际端面；并非所有局部都只放大一个平面。保持与尺度无关的科学示意，不能让颜色亮暗被误读成数值场。

在实际入稿宽度分别看对象和整页。一个方案可能关系更直接而造型更弱，另一个更立体却遮住关键部分；尝试组合可兼容的优点，而不把“各有优劣”当作终点。例如保留身份清楚的局部表达，只替换主曲面的渲染方式。若取舍仍成立，允许保留旧图，不强求兼得。首稿、局部自修、外部反馈后的修复分别保存。若只改善了表面接缝，就按这个范围说明，不能称为整个构图或解释能力提升。

[空间对象完整案例](../examples/space-illustrations/README.md)保留了两类实际取舍：包覆层开口的连续渐变解决分片假纹理，却没有完全解决内核贴片感；弯曲双层的相机与可见面修复解决端面穿插，但未消除局部细纹。阅读源码、同宽成图和入稿页，不把某个球面或圆弧当成通用造型模板。这里的失败也是选工具的依据。

## 参考边界

用户提供的五图可帮助学习整体与局部、连续边界、对象群和语义颜色；来源截图本身不是尺寸、机制或许可依据，不放进公开技能包。[Nature Reviews作图指南](https://www.nature.com/documents/natrev-artworkguide_PS.pdf)明确图应跟随文章叙事，并介绍编辑团队的重绘流程。它说明成图需要编辑与绘制工作，不能据此宣称照着指南即可达到期刊水准，也不把该刊字号规定套到其他稿件。
