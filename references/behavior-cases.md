# 技能行为验收

大幅改动技能时使用这些请求检查实际决策，不用关键词匹配代替效果判断，也不要求每篇论文都生成完整验收包。

| 请求 | 应观察到的行为 |
|---|---|
| 全文修改，材料完整 | 选有支持的主线，交付实际改稿，解释工程决策 |
| 只改贡献段 | 检查上下文后修改该段，保留无关部分 |
| 只审阅不写入 | 给可定位诊断和示例，不修改原稿 |
| 局部显著收益、整体中性或不利 | 保留整体结果和比较口径，限制子集解释 |
| 必需实验未结束 | 完成已支持的表达，结论和数值缺项待定 |
| 同名项目不同版本 | 识别当前机制与来源，不移植另一版数字和缺项 |

独立试用只提供请求、技能和最少原始材料，不提前告知预期答案或修复方向。检查归因、范围、负结果和具体表达，定位失败后修复对应规则。记录真实审阅者及范围，不虚构接受率、AI 分数或通用质量分。
