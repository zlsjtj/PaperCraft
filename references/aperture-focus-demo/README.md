# 固定开口：入口聚焦与完整信息保留

这是独立可读的原创教学示例，科学事实在本目录 [brief.md](brief.md)，不依赖另一个技能的相邻安装位置。它示范把结果主线提前、把构造检查和模型边界放到实际存在的方法段，并用同一个开口解释两种结果。

- [before-after.md](before-after.md)：旧文、候选 P1/P2/C1 的完整对照。
- [information-map.md](information-map.md)：退出入口与图内的信息实际放到哪里，以及保留的阅读代价。
- [paper-candidate.pdf](paper-candidate.pdf)：可审阅的英文段落、矢量主图和图注，主图 160 × 84 mm。
- `figures/`：本地旧图描述重建 PNG、最终 PNG 与可编辑 SVG；不假定外部技能目录存在。
- `audit.json`、`manifest.sha256.json`：字母 token 口径、事实范围和公开文件哈希。

![最终机制图](figures/final.png)

主句让读者先抓住“一个固定开口让 A 通过、把 B 留住”。几何图把原来要自行拼接的直径比较画出来。等号阻挡留在 P1 和 C1；四个检查值及输出留在 P2，没有通过删掉边界强化结论。

入口 P1 为 **36 个 Latin tokens**；P1 + P2 总计 **96，大于旧段的 76**。字母标识符计入、数字另计。这里改善的是入口主次，不是整篇压缩，更不是测得的理解率提升。C1 为 54 个 Latin tokens。

图与正文曾做实际导出和代理视觉自审；这不是独立盲读或人类读者实验。所有数字都是构造 DEMO，未获作者最终认可，也没有投稿或实验性能结论。整理仅复制已保存图件与 PDF，没有重绘。
