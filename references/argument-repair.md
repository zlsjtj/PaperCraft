# 让论证按读者的问题展开

事实齐全不等于容易理解。先找少数实际阅读阻碍：读者在哪一处尚未看见问题，就被要求记住规则；哪项实现工作只有清单，没有必要性；哪组结果必须读到后面才知道为何测。只修复有产物依据的阻碍，不给每段强加固定句式。

## 先排理解次序，再改句子

对核心方法画一条短阅读路径：**看见困难的具体实例 → 实际变化 → 为什么可行 → 完整条件与边界**。这是检查依赖的办法，不是每篇固定章节。读者需要先知道的定义保留在前；其余形式化与实现条件放在实例之后。优先移动已有内容、改段落主句和合并重复，不默认增加一段。

以同样事实试写两种确有区别的入口，例如从一个反例引出设计，或从完整代价解释为什么需要选择。只在路线不确定时比较两版。保留使读者少回看、又不压没关键工作的版本；篇幅和术语数量不参与打分。已经适合的摘要或段落不必为显示改动而重写。

## 把工作组织成有判别力的证据

先说设计或实验回答什么，再列必要配置。对每组主要证据确定：**读者可能提出的另一种解释 → 为区分它而作出的比较 → 实际得到的判断**。匹配更强对照、独立选择配置、正确性检查、失败控制各有不同作用；不能把它们合成同一项性能证明。没有直接对照的组件，不单独分配系统收益。

改结果段前，以实际比较为单位整理材料：哪些条件相同、什么改变、主要结果及代价是什么、哪个反例会改变判断。用[贡献与证据记录](../templates/claim-evidence-ledger.md)的一行绑定它们，而不把收益、成本和边界分散成互不相干的主张。材料没有给出代价时记为未知，不能填成零。每一行只服务于一个实际判断，不要求每项指标都进入摘要。

从这个比较单元写一段能独立读懂的论证：先给发现与比较对象，紧接改变其含义的成本或反例，再解释它支持到哪里。选择进入摘要的结果也保留足以避免误读的代价；详细数值在对应结果段。不要先抽走一条亮眼数字，再到段末追加笼统的谨慎措辞。参见[同一收益下怎样保住代价](result-pair-example.md)。

压缩后直接对照产物补齐记录中的实际段落位置：收益留下时，其成本有没有也留下；必要条件移出入口后，方法是否真的承接；缺失对照是否仍限制相应归因。已有数据表可以承载明细，但决定结论的不利比较不能只剩表中一个数。修复遗漏优先替换重复解释，不默认加长。源码给出的状态转换、退出条件和例外沿一次操作核对，避免只保留顺利路径。

重复限定按作用合并：定义比较范围或限制眼前结论的内容贴近判断；相同提醒保留最近的一处即可。平台、工具链与完整参数放在方法，独有事实仍在正文有实际落点。编辑过程、文件保护、候选选择及验收状态进入交付记录；真实研究状态和未完成研究本身仍应在论文中清楚说明。

| 可定位问题 | 优先动作 | 必须保留 |
|---|---|---|
| 规则在例子之前，读者尚不知为何需要 | 前置已有实例；定义只提前到理解所需处 | 形式化、适用条件、反例及正文承接位置 |
| 工作只列步骤 | 用实际困难和必要决定组织段落 | 真实检查及其有限证明范围 |
| 配置先于实验目的 | 先交代它排除的替代解释，再说明具体配置 | 全部选择条件、失败样本、数据范围 |
| 结果埋在验证流水账中 | 先写主要发现，再给控制、细节和代价 | 分子分母、统计口径、负结果 |
| 主贡献与支撑混为多项创新 | 按作用分层，围绕实际差异组织 | 继承关系，不虚增独立算法 |

## 局部验证后检查整篇

局部试写有效后，全文任务继续检查方法、实验、结果和讨论的阅读路径；不能仅将一段变短就称全文完成。用[全文对应表](../templates/argument-map.md)记录必要事实所在位置及每节修改或保留理由。移动章节、图、公式后同步修正交叉引用；保存对象内容和移动映射，不能只检查数量。

删除独有事实必须有授权；压缩或移位则记录实际承接段，必要内容仍在论文内。重要数字按原始口径复算，算术修正单列；未测原因保持未知。主张与证据之间的缺口不能靠表达补齐。

先看相同范围的前后产物，再看改动理由。比较读者首先抓住什么、哪些工作更有必要性、哪里仍需往返查找；没有真实读者时只称模型辅助评估。新增复现细节单独记录，不冒充叙事增量。
