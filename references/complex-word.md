# 长稿与复杂 Word 的受控修订

适用于原生公式相邻段、混合 run、引用域、交叉引用、图表及已有高亮/修订。`review_docx.py` 拒绝这些目标是保护措施，不是停止任务的理由。使用当前宿主真实 documents 技能的格式感知流程，先读其 OOXML 指引；一个主编辑持有最终 Word。

## 修改前

冻结原稿、哈希及图源/数据来源；读取所有正文、原生公式、表格、图注、参考文献与声明。为要动的段落建立稳定 ID 和准确原文断言，记录标题层级、段落/run 格式、域、书签、超链接与关系目标。用相邻短引文定位，最终页码由渲染确认。改前先写阅读问题及四项修改理由，避免把全文扁平化后重建。

## 修改方法

- 普通纯文字段可用现有 helper。公式相邻段只改授权文字节点或文字片段，保留原 `m:oMath` 子树与其顺序；若重排文字，用独立占位符绑定每个公式节点，插回原节点，逐一断言出现一次。不得用公式显示文字重造公式。
- 混合格式段要按文本片段保留格式。例如段首加粗标签不能因沿用第一个 run 的属性而把整段变粗；移动或改写标签后，应同时核验标签范围和正文范围，再查看实际页面。普通 helper 已拒绝 mixed run formatting，格式感知接续脚本也必须保留这一边界。
- 保留脚注标记、引用域、书签边界、超链接、图关系和表结构。允许文字变化不等于允许破坏这些对象；无法安全处理的对象留原样，继续其它修订，并明确具体缺项。
- 图修订仅替换对应图像及可编辑源，保持关系 ID 可解析，按真实入稿尺寸核验。对象数不变仍要检查数值、含义和图注；只换色任务不得顺带改布局或图内内容。
- 新黄标只标本轮新增/重写文本。不要把数学节点整体重构成高亮文本；公式内容保持不变时，在报告定位周围文字修改。清稿只移除本轮黄标，原有高亮/原生修订保留。
- 对新增、删除、移动、格式与图片替换都写变更映射；无原生 Track Changes 就明确是黄色审阅标记。报告不应声称黄色标记呈现了删除。

## 内容保护检查

运行只读检查器：

```text
python scripts/audit_preservation.py original.docx revised.docx --policy protection.json --out preservation.json
```

最小 policy（文字必须来自原稿，不能把示例当保护内容）：

```json
{
  "protected_paragraphs": [
    {"label": "AI disclosure", "text": "Exact paragraph from the source."},
    {"label": "Reference 1", "text": "Exact first bibliography paragraph."}
  ],
  "lock_citation_tokens": false
}
```

省略 policy 仍能检查原生公式、表格、图数量、域/书签/链接身份、脚注/尾注与参考源部件。声明和手写参考文献依赖明确 policy；未提供标为 **NOT_CONFIGURED**，不得声称已保护。受保护段按完整可见文字匹配，必须在源稿有记录；需要保留格式时使用 `"mode": "xml"`（默认 `"text"`）。同文段多处存在时要求两稿出现次数相同。`lock_citation_tokens` 可锁定数字方括号引文的多重集合；不认识作者年份引用，也不验证文献真实性。

检查器分别记录：

1. 公式 `m:oMath` 的数学结构/文本签名与独立 C14N XML 签名，按原顺序逐个比对；纯 run 外观不同进入 XML 审阅，数学内容变化失败。它不证明数学推导正确。
   两稿均无原生公式时，公式两项为 `NOT_EXERCISED`，不把空集合一致称为原生公式能力已验证；仅一稿为空时仍按新增/删除公式检测失败。普通文本中的数学记号另按改动段核对。
2. 表格行/单元格顺序、文本、公式、合并属性；不能只凭两表数量相等通过。
3. 域代码、书签名称、超链接关系、注释引用及图数量；图内容允许按当前任务变化，另走交接和视觉审阅。表格重排、公式重排或新增默认会失败，授权实质修改需另行逐项审计，而非关闭整个检查。
4. 附属脚注/尾注/文献源部件与关系目标、明确保护的声明/文献段。

每项记录输入输出哈希、状态与差异索引。默认检查不锁定所有普通正文数字，也不能识别所有第三方 Word 扩展。仍须从变更映射逐项核对新旧数字、单位、地址、比较对象、声明、引用与公式周围论证。

## 最终交付

渲染审阅稿、清稿和中文报告，查看每一页；核对 Word/PDF 的公式、分页、表头、图内文字及字段结果。分别记录结构保护、科学内容审阅、视觉审阅、作者认可。受控 OOXML 的一份长稿通过，不代表所有复杂 Word 文件都已覆盖。
