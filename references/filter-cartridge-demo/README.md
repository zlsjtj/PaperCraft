# 过滤盒：先交代操作变化，再解释必要组成

这是构造的几何教学例，事实由维护者为迁移试用给定，不是真实研究结果。完整输入和原段落见 [source_material.md](source_material.md)，实际改文见 [revised-paragraph.md](revised-paragraph.md)。

原段逐个列外壳、接口、密封圈、框架和滤层，读到后半段才知道为何需要这些组成。改文先对比“拆外壳”和“固定外壳、侧向抽出内盒”，然后让固定接口、随动滤层和保持层序分别解释这个操作如何成立。停流条件随操作出现，未验证的性能不包装成收益。

新上下文按技能生成了这段文字和图；绘图初稿仍需一轮针对重复句的反馈，引擎也需补齐 motion。它是有限的跨题材实践，不是盲测优胜或稳定一次生成的证据。没有真实读者认可，没有原始模型日志，不能把材料内一致性写成已验证的机械效果。配套 FigureCraft 的 examples/filter-cartridge 保留初稿、最终矢量图和重建脚本。
